# Cybersecurity Lab Write-ups

Documentação dos laboratórios práticos que realizo durante meus estudos de cibersegurança.

## Plataformas

- [PortSwigger Web Security Academy](portswigger/)

## Trilha atual

### Authentication vulnerabilities

A documentação está organizada conforme os três grupos da trilha de autenticação da PortSwigger:

- [Password-based login](portswigger/authentication/password-based/)
- [Multi-factor authentication](portswigger/authentication/multi-factor/)
- [Other authentication mechanisms](portswigger/authentication/other-mechanisms/)

Acompanhe o andamento dos 14 laboratórios no [índice de autenticação](portswigger/authentication/README.md).

## Estrutura de cada write-up

Cada laboratório apresenta:

- objetivo e conceitos estudados;
- análise da vulnerabilidade;
- metodologia e etapas da exploração;
- evidências técnicas;
- impacto, causa raiz e correções recomendadas;
- aprendizados pessoais e referências.

## Aviso ético

Os testes documentados neste repositório são realizados exclusivamente em ambientes educacionais e deliberadamente vulneráveis, com autorização para prática. As técnicas aqui descritas não devem ser usadas contra sistemas sem permissão explícita.
